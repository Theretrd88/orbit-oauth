Privacy Policy

Orbit Uploader is a desktop program running on its owner's computer. This website only hosts a static page that shows an authorization code; it has no server, no database, no cookies and no analytics.

  • What the tool receives from TikTok: basic profile information (display name) and an access token, after the account owner approves access.
  • Where it is stored: only on the owner's computer, in a private local file. Nothing is sent to any third party.
  • What it does with it: uploads the owner's own videos to the owner's TikTok drafts.
  • Revoking access: in TikTok, Settings and privacy → Security and permissions → Apps, or by deleting the local token file.
